sndbox is a desktop workflow builder for repeatable browser and system automation. Build a workflow from typed nodes, run it with the local or self-hosted runner, and inspect the inputs, outputs, logs, and evidence produced by each execution.

## One workflow, visible end to end

The editor keeps the automation and its execution history together. Configure a node on the canvas, map data from earlier steps, test it, then open the run inspector to see what happened.

<Steps>
  <Step title="Choose a real trigger">
    Start manually, on a schedule, when a file changes, or when matching Gmail messages arrive.
  </Step>
  <Step title="Connect the work">
    Add browser, HTTP, file, data, notification, approval, or communication nodes. The editor only exposes settings the selected node implements.
  </Step>
  <Step title="Run with explicit permissions">
    sndbox shows file-system, network, command, browser, and secret boundaries before execution.
  </Step>
  <Step title="Inspect the evidence">
    Review node inputs and outputs, logs, retries, screenshots, downloads, and browser diagnostics from the execution inspector.
  </Step>
</Steps>
