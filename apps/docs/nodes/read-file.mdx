**Node type:** `read_file` · **Version:** `1` · **Category:** Data

Read text from an approved file. This node is not marked with the catalogue's generic side-effect flag. That classification is not a guarantee that every configured operation is read-only; review the concrete action and its destination.

## When to use this node

- Load a text, JSON, CSV, or prompt file from an approved path.
- Pass file content to a parser, AI, or Code node.

## Example: Read a JSON settings file

Read at most 1 MiB of UTF-8 text, then map content to Parse JSON.


```json title="Example settings"
{
  "path": "C:\\Automation\\settings.json",
  "encoding": "utf8",
  "maximumBytes": 1048576
}
```

This shows the important settings, not a complete exported node. Local paths must be selected, mapped from a trusted path, or covered by the runner's approved boundary.


1. Select or map a trusted file path.
2. Keep maximumBytes close to the expected file size.
3. Map content into Parse JSON and inspect its value output.


## Configuration

| Field | Type | Default | What it controls |
| --- | --- | --- | --- |
| `path` | path | `""` | Approved local file or folder path. |
| `encoding` | string | `"utf8"` | Text encoding used to read the file. The current runner accepts UTF-8 only. Values: `utf8`. |
| `maximumBytes` | number | `10485760` | Maximum accepted file, response, screenshot, or download size in bytes. |

<Note>Only UTF-8 text is accepted. The byte limit is clamped to 1–104857600 bytes.</Note>

## Workflow JSON

The editor stores this node with the following implemented default configuration:

```json title="Default node configuration"
{
  "type": "read_file",
  "version": 1,
  "configuration": {
    "path": "",
    "encoding": "utf8",
    "maximumBytes": 10485760
  }

```

Values may be entered literally or mapped from an earlier compatible output when the inspector exposes a mapping control. See [Variables and data mapping](/workflows/variables-and-data).

## Execution behavior

- The node returns content, the trusted path, and bytes read.
- The maximum size is enforced before unbounded file content enters execution data.
- The editor catalogue declares `content` (string), `path` (path), `bytes` (number) for mapping. The execution inspector can contain additional evidence fields; inspect a real result before selecting nested paths from object or any outputs.

## Common issues

- Binary files are not appropriate input; use a node designed for that artifact.
- A plain string path from an untrusted source may not carry the approval provenance required by the runner.
