**Node type:** `press_key` · **Version:** `1` · **Category:** Browser

Send a validated key combination. This node is not marked with the catalogue's generic side-effect flag. That classification is not a guarantee that every configured operation is read-only; review the concrete action and its destination.

## When to use this node

- Submit a form with Enter, dismiss a dialog with Escape, or use a supported shortcut.
- Trigger keyboard behavior when clicking is not equivalent.

## Example: Submit search with Enter

Run Press Key immediately after filling the focused search field.


```json title="Example settings"
{
  "key": "Enter",
  "timeoutMs": 30000
}
```

This shows the important settings, not a complete exported node.

## Execution behavior

- The key is sent to the active page using the current focus context.
- The timeout bounds dispatch and browser response, not all work started by the shortcut.
- The editor catalogue declares `result` (any) for mapping. The execution inspector can contain additional evidence fields; inspect a real result before selecting nested paths from object or any outputs.

## Common issues

- If focus moved, the page or wrong control may receive the key.
- Operating-system shortcuts and application-level browser shortcuts are not the same as page keyboard input.
