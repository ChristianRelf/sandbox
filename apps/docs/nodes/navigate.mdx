**Node type:** `navigate` · **Version:** `1` · **Category:** Browser

Load a URL in the active session. This node is not marked with the catalogue's generic side-effect flag. That classification is not a guarantee that every configured operation is read-only; review the concrete action and its destination.

## When to use this node

- Load the next page in an active managed browser session.
- Wait for an initial page milestone before interaction begins.

## Example: Open a report page

Navigate to the portal and wait until the DOM is ready, with a 30-second bound.


```json title="Example settings"
{
  "url": "https://portal.example.com/reports",
  "waitCondition": "dom_ready",
  "timeoutMs": 30000
}
```

This shows the important settings, not a complete exported node.


1. Connect from Open Browser or another action in the same session path.
2. Choose the weakest readiness condition that is sufficient.
3. Add Wait For when a specific dynamic control must become available.


## Configuration

| Field | Type | Default | What it controls |
| --- | --- | --- | --- |
| `url` | string | `""` | Literal URL or mapped URL value. |
| `waitCondition` | string | `"dom_ready"` | Page condition Navigate waits for before succeeding. Values: `dom_ready`, `page_loaded`, `network_idle`, `element_visible`. |
| `timeoutMs` | number | `30000` | Maximum time for this operation in milliseconds. |
| `locator` | locator | — | Recorded locator bundle. sndbox prefers accessible role/name data and retains fallbacks. Shown when `waitCondition` is `element_visible`. |

## Execution behavior

- The URL must be inside the workflow's approved network boundary.
- dom_ready, page_loaded, network_idle, and element_visible describe different milestones and can complete at different times.
- The editor catalogue declares `result` (any) for mapping. The execution inspector can contain additional evidence fields; inspect a real result before selecting nested paths from object or any outputs.

## Common issues

- network_idle may never arrive on pages with analytics, streaming, or polling.
- A successful navigation does not guarantee that a later dynamic element is ready.


## Where it can run

- Desktop local runner
- Paired self-hosted runner
- Managed browser worker
