**Node type:** `delete_path` · **Version:** `1` · **Category:** System

Delete an explicitly approved path. This node can change external state or produce an external side effect.

## Configuration

| Field | Type | Default | What it controls |
| --- | --- | --- | --- |
| `path` | path | `""` | Approved local file or folder path. |
| `recursive` | boolean | `false` | Include nested folders, or permit recursive deletion for Delete File or Folder. |

<Note>The selected path must be inside an approved folder. Test runs require an additional destructive-action confirmation.</Note>
