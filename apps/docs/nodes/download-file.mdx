**Node type:** `download_file` · **Version:** `1` · **Category:** Browser

Save a browser download safely. This node does not declare an external side effect.

## Configuration

| Field | Type | Default | What it controls |
| --- | --- | --- | --- |
| `locator` | locator | `null` | Recorded locator bundle. sndbox prefers accessible role/name data and retains fallbacks. |
| `destinationFolder` | path | `""` | Approved folder that receives the output. |
| `filename` | string | `""` | Optional destination filename. |
| `collisionBehaviour` | string | `"rename"` | Create a unique name, overwrite, or fail when the filename exists. Values: `rename`, `overwrite`, `fail`. |
| `maximumBytes` | number | `104857600` | Maximum accepted file, response, screenshot, or download size in bytes. |
| `timeoutMs` | number | `60000` | Maximum time for this operation in milliseconds. |
