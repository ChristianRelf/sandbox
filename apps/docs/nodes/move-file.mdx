**Node type:** `move_file` · **Version:** `1` · **Category:** System

Move within approved folders. This node can change external state or produce an external side effect.

## Configuration

| Field | Type | Default | What it controls |
| --- | --- | --- | --- |
| `source` | path | `""` | Source file or folder inside an approved boundary. |
| `destinationFolder` | path | `""` | Approved folder that receives the output. |
| `renameTo` | string | `""` | Optional replacement filename. |
| `overwrite` | boolean | `false` | Allow replacement when the destination already exists. |
