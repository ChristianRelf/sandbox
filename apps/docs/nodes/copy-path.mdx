**Node type:** `copy_path` · **Version:** `1` · **Category:** System

Copy within approved folders. sndbox classifies this node as side-effecting, so tests or automatic runs can require additional confirmation and permission review.

## When to use this node

- Create a backup before a destructive or mutating step.
- Copy a file or folder between approved local boundaries.

## Example: Back up a configuration folder

Copy a reviewed source folder into a dated backup destination.


```json title="Example settings"
{
  "source": "C:\\Automation\\config",
  "destination": "C:\\Automation\\backups\\config-latest",
  "overwrite": false
}
```

This shows the important settings, not a complete exported node. Local paths must be selected, mapped from a trusted path, or covered by the runner's approved boundary.


1. Approve the source and destination boundaries.
2. Leave overwrite disabled for the first run.
3. Inspect the destination and copied entry count before relying on the backup.


## Configuration

| Field | Type | Default | What it controls |
| --- | --- | --- | --- |
| `source` | path | `""` | Source file or folder inside an approved boundary. |
| `destination` | path | `""` | Destination file or folder path. |
| `overwrite` | boolean | `false` | Allow replacement when the destination already exists. |



## Workflow JSON

The editor stores this node with the following implemented default configuration:

```json title="Default node configuration"
{
  "type": "copy_path",
  "version": 1,
  "configuration": {
    "source": "",
    "destination": "",
    "overwrite": false
  }
}
```

Values may be entered literally or mapped from an earlier compatible output when the inspector exposes a mapping control. See [Variables and data mapping](/workflows/variables-and-data).

## Inputs

This node has no typed ports in this direction.

## Outputs

| Port | Type | Required | Description |
| --- | --- | --- | --- |
| `result` | `any` | No | Result |

## Execution behavior

- Files and folders are supported, and the output identifies source, destination, and copied entry count.
- Replacement is rejected unless overwrite is explicitly enabled.
- The editor catalogue declares `result` (any) for mapping. The execution inspector can contain additional evidence fields; inspect a real result before selecting nested paths from object or any outputs.

## Common issues

- Copying a folder into itself or a descendant is invalid.
- Large directory trees can take time and produce many filesystem operations.


## Where it can run
