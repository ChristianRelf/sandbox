**Node type:** `copy_path` · **Version:** `1` · **Category:** System

Copy within approved folders. This node can change external state or produce an external side effect.

## Configuration

| Field | Type | Default | What it controls |
| --- | --- | --- | --- |
| `source` | path | `""` | Source file or folder inside an approved boundary. |
| `destination` | path | `""` | Destination file or folder path. |
| `overwrite` | boolean | `false` | Allow replacement when the destination already exists. |
