**Node type:** `javascript_code` · **Version:** `1` · **Category:** Data

Transform workflow items in a restricted JavaScript runtime. sndbox classifies this node as side-effecting, so tests or automatic runs can require additional confirmation and permission review.

## When to use this node

- Transform data when built-in mapping and parser nodes are not enough.
- Author reusable HTML, JavaScript, or CSS source for Web Builder.

## Example: Transform mapped JSON with JavaScript

Run JavaScript locally, reading the mapped value from SNDBOX_INPUT and printing a JSON result.


```json title="Example settings"
{
  "language": "javascript",
  "sourceCode": "const input = JSON.parse(process.env.SNDBOX_INPUT ?? \"null\");\nconsole.log(JSON.stringify({ count: input.rows.length }));",
  "executionMode": "run",
  "timeoutMs": 30000
}
```

This shows the important settings, not a complete exported node. Local paths must be selected, mapped from a trusted path, or covered by the runner's approved boundary.


1. Map the source value to input.
2. Run in the full editor and resolve diagnostics.
3. Inspect result, stdout, and exit behavior before connecting downstream nodes.


## Configuration

| Field | Type | Default | What it controls |
| --- | --- | --- | --- |
| `language` | string | `"javascript"` | Language used for highlighting, diagnostics, AI-assisted authoring, and optional execution. |
| `sourceCode` | string | `"// Return JSON data or an array of items.\nreturn items.map(item => ({ ...item.data, processed: true }));\n"` | Complete source stored in the workflow. Open Edit code for the full editor and live Problems panel. |
| `executionMode` | string | `"run"` | Return the source unchanged, or execute supported script languages and wait for their result. |
| `itemMode` | string | `"all_items"` | Configuration value for Item Mode. |
| `runtimeVersion` | string | `">=20"` | Configuration value for Runtime Version. |
| `helperLanguageVersion` | number | `1` | Configuration value for Helper Language Version. |
| `dependencies` | array | `[]` | Configuration value for Dependencies. |
| `timeoutMs` | number | `30000` | Maximum time for this operation in milliseconds. |

Values may be entered literally or mapped from an earlier compatible output when the inspector exposes a mapping control. See [Variables and data mapping](/workflows/variables-and-data).

## Execution behavior

- Source mode returns the file without executing it; HTML and CSS always use source mode.
- Run mode invokes the installed node or python executable and requires command-execution approval.
- The editor catalogue declares `items` (array), `result` (any) for mapping. The execution inspector can contain additional evidence fields; inspect a real result before selecting nested paths from object or any outputs.

## Common issues

- SNDBOX_INPUT is a JSON string, so parse it before treating it as an object.
- Keep secrets out of source and stdout because both can appear in workflow or execution records.
