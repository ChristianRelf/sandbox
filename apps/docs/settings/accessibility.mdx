## Reduce motion

Reduces non-essential transitions and animated feedback. Functional state changes and progress remain exposed through text and semantics.

## Increased contrast

Strengthens control, text, and focus boundaries for the current theme. Success, warning, error, and enabled state retain text or accessible names instead of relying on color alone.

## Accessible editor by default

Opens the companion graph editor whenever a workflow is opened. It supports add, inspect, 20-pixel directional move, true/false branch connection, and connection removal with native controls.

All application controls keep a visible two-pixel focus indicator. See [Accessible editor](/workflows/accessible-editor) for the complete graph operations.
