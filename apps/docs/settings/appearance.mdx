---
title: "Appearance settings"
description: "Adjust theme, surface, accent, density, and sidebar width without changing workflow content."
icon: "palette"
---

| Setting | Implemented choices |
| --- | --- |
| Theme | System, Light, Dark |
| Dark surface | Charcoal, OLED |
| Accent | Lime, Violet, Blue |
| Density | Comfortable, Compact |
| Sidebar | Default or compact |

The compact density reduces spacing in controls and wide tables. Compact sidebar gives the canvas more horizontal room. The chosen accent is used for focus and selected state but does not become the only indicator of success, warning, or failure.

Appearance is stored as a user preference. Screenshots captured during a run still reflect the real managed browser page, not this application theme.
