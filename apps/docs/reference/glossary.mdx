title: "Glossary"
description: "Definitions for the product terms used throughout sndbox."
icon: "book-a"
---

**Connection** — Host-owned provider credential referenced by ID from a workflow.

**Control edge** — Graph edge that determines which node becomes eligible next.

**Execution** — One run of one saved workflow revision, with node evidence.

**Input binding** — Typed record that supplies a literal, output path, template, protected variable, or connection to a node field.

**Managed browser profile** — Isolated local or cloud browser state plus viewport/network policy metadata.

**Node** — Versioned unit of workflow configuration, typed ports, and execution behavior.

**Package integrity** — `sha256:` digest identifying one immutable plugin archive.

**Protected variable** — Secret value resolved by the host from its name; plaintext is not stored in ordinary workflow JSON.

**Published revision** — Exact workspace revision approved and selected for governed execution.

**Runner** — Local, self-hosted, hosted, or managed-browser execution agent.

**Runner pool** — Workspace/environment-scoped set of compatible runners plus routing strategy and concurrency ceiling.

**Side effect** — Node behavior that changes an external system, file, stored state, communication, or approval state.

**Trusted path** — File/folder value selected or produced inside an approved host boundary.

**Workflow state** — Per-workflow value committed only after a complete successful run.
