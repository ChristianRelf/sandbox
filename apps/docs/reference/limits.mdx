## Desktop and browser

- Window minimum: 1040 × 680.
- Open Browser viewport editor: 320–3840 × 240–2160.
- Browser operation timeout editor: 100–120000 ms.
- Browser session hard ceiling in the sidecar: 4 hours.
- Screenshot default maximum: 10 MB.
- Download default maximum: 100 MB; editor maximum 2048 MB.
- Read File editor maximum: 100 MB.
- Workflow import/export: 2 MB.
- Gmail polling: 1–60 minutes.
- Approval expiry: 1–10080 minutes.

## AI, Code, and Web Builder

- AI node instruction: 100000 characters.
- AI node output request: 64–32000 tokens.
- AI node timeout: 1000–300000 ms; default 90000 ms.
- AI workflow-builder instruction: 8000 characters.
- Code-editor AI instruction: 8000 characters; current source context: 2 MB.
- Code source: 2 MB.
- Python/JavaScript run timeout: 100–120000 ms; default 30000 ms.
- Code standard output and standard error: 64 KiB each.
- Web Builder HTML, JavaScript, and CSS: 4 MB combined.
- Web Builder port: 0–65535; `0` chooses an available loopback port.

## API

- Default budget: 240 requests per IP per minute.
- Health budget: 60 per minute.
- Idempotency key: 16–200 safe ASCII characters.
- Idempotency retention: 24 hours.
- TypeScript client retry count: 0–5, default 2.
- Personal-token maximum expiry: 90 days.
- Service-account policy: 1–365 days.

## Collections

- Transformation input and output: 10,000 items each.
- One item JSON value: 1 MiB.
- Aggregate result: 16 MiB.
- Cartesian Merge: 25,000 results, also bounded by the node's lower configured maximum.
- Loop Over Items: 10,000 iterations, concurrency 16, and at most 10 configured iteration retries.
- Cross-run Remove Duplicates: 50,000 committed keys per node.
- Execution inspector preview: 100 items per node; counts remain authoritative and runtime collections remain complete.

## Plugins

- Default memory: 32 MB.
- Default fuel: 25 million.
- Default timeout: 30 seconds.
- Input/output: 1 MB.
- Host response: 2 MB.
- Manifest timeout request: no longer than five minutes; host may lower it.
- Temporary and persistent storage class: at most 100 MB each.

Deployment policy can impose stricter limits. The operation error and generated API schema are authoritative for a specific request.
