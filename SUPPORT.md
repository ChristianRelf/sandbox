# Support

Choose the channel that matches the request:

| Need | Channel |
| --- | --- |
| Setup and usage questions | [Documentation](https://docs.sndbox.app) or [Discord](https://discord.gg/sndbox) |
| Reproducible bug in this repository | [GitHub issue](https://github.com/sndboxhq/sandbox/issues/new/choose) |
| Account, billing, or private diagnostic help | [Private support portal](https://app.sndbox.app/support) |
| Security vulnerability | [Private vulnerability report](https://github.com/sndboxhq/sandbox/security/advisories/new) |

GitHub issues are public. Search for duplicates and remove secrets, personal
data, private workflow contents, tokens, webhook URLs, logs containing customer
data, and local file paths that reveal sensitive information. A minimal
reproduction using synthetic data is much easier to investigate.

The community may help with usage questions, but response times are not
guaranteed. Paid or contractual support terms, if any, are governed by the
applicable agreement rather than this repository policy.

Feature ideas are welcome through the feature request form. Questions about a
planned contribution should begin with [CONTRIBUTING.md](CONTRIBUTING.md).
