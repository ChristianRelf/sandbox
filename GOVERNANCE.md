# Governance

sndbox is maintained by the repository owner with input from contributors and
users. This document describes repository decision-making; it does not create a
partnership, employment relationship, or service commitment.

## Roles

- **Users** run sndbox and provide feedback.
- **Contributors** submit issues, documentation, tests, designs, or code under
  [CONTRIBUTING.md](CONTRIBUTING.md).
- **Reviewers** are trusted contributors invited to review particular areas.
- **Maintainers** triage reports, set direction, merge changes, manage releases,
  and enforce project policies.
- **Repository owner** has final responsibility for product direction, security,
  legal obligations, access, and maintainer appointments.

The current repository owner and maintainer is
[@ChristianRelf](https://github.com/ChristianRelf). Ownership rules are recorded
in `.github/CODEOWNERS`.

## Decisions

Routine decisions are made through issue and pull-request discussion. The
maintainer seeks relevant technical input and aims for rough consensus, but may
make the final decision when consensus is absent, timelines require it, or the
decision affects security, privacy, legal obligations, product strategy, or
operations.

Material changes to public APIs, workflow schemas, persisted data, permissions,
authentication, pricing, or release integrity should have a written proposal
before implementation. Security incidents may be handled privately until
coordinated disclosure is safe.

## Becoming a reviewer or maintainer

Appointments are based on sustained, constructive contributions; sound
judgment; reliable reviews; security awareness; and adherence to project
policies. Access is least-privilege, periodically reviewed, and removed when no
longer needed. There is no automatic entitlement to repository access based on
contribution count.

## Changes to governance

Governance and policy changes use the same reviewed pull-request process as
code. The repository owner may make an urgent change to protect users or the
project, with an explanation recorded afterward when disclosure is safe.
